# Code Challenges

Weekly backend challenges to grow from junior to production-ready developer.
Stack: Python, FastAPI, SQLAlchemy, PostgreSQL, Docker.

## Grading (100 points)
| Area | Points |
|------|--------|
| Works correctly | 40 |
| Code quality and structure | 25 |
| Tests | 15 |
| Security and error handling | 10 |
| Readability and docs | 10 |

## Levels
1. CRUD, validation, error handling
2. Auth, roles, pagination, search
3. Testing, migrations, Docker
4. Security, rate limiting, logging, performance
5. System design, background jobs, deployment

Score 80+ twice in a row: move up a level.
Score below 60: repeat the topic.
